Minecraft Plugin - "BiomeMastery"

Total Downloads Initial Release Links
Code Plugin Page Wiki
0 Dec 19, 2025 GitHub Plugin Page GitHub Wiki

This is a Minecraft plugin that lets players "level up" each biome that exists in Minecraft and will give them rewards, which can be edited in the config file. This is something thats not possible in normal Minecraft. It is available for free to the public.
Players who use this, have their data stored in a SQL database or in a YAML file. The plugin supports both storage methods.


Minecraft Plugin - "A True or False Quiz"

This is a Minecraft plugin that runs an automated quiz. It only accepts true or false answers. It comes with pre-set questions but they can be removed, edited and new ones can be added. If the user wants the players to win rewards from finishing a quiz, this can also be setup in the config. It is available for free to the public.
