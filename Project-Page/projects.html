Minecraft Plugin - "Death Holograms"

The idea behind this plugin was to find a plugin that was already popular in the Minecraft community, but had fallen victim to out-of-date code, and was no longer being maintained. I found a highly downloaded plugin, that basically created floating text (holograms) at the location a player dies. I didnt look at their code, Im not even sure if it was available to the public, but I decided I wanted to see if I could code it from scratch using my own knowledge. Within a few days the plugin was born.

The most difficult part of this project was the impact on server performance. When it comes to Minecraft holograms, they are usually classed as an entities (like animals). Lots of entities, means potential performance issues. I researched alot and found a more modern way to create holograms. This new API didnt use entities, but it was only available in newer versions of Minecraft. This left me with a problem, as I wanted the plugin to be compatible with as many versions of Minecraft as possible.

Long story short, I added optional dependency support for alternative hologram plugins, that used packets to create holograms, instead of entities in older versions of Minecraft. This allowed players to have a choice on how to utilise my plugin.

This is a Minecraft plugin that lets players "level up" each biome that exists in Minecraft and will give them rewards, which can be edited in the config file. This is something thats not possible in normal Minecraft. It is available for free to the public.

When designing this plugin, my goal was to learn more about databases. It fully supports MySQL, or file storage. Player data gets loaded, saved and updated on a seperate thread, to reduce any lag or performance issues. It also has a built in caching system, to reduce the amount of times it needs to access the database.

Another neat feature when creating this, was that I added in a multi-language system. I then implemented it into my other plugins, and its something I do as standard now. Using AI I have already pre-translated all the messages/prompts into German, French, Dutch and Spanish. Although the user can translate and edit any of the messages themselves, so it technically supports any language.


Minecraft Plugin - "A True or False Quiz"

This is a Minecraft plugin that runs an automated quiz. It only accepts "true" or "false" as answers. It comes with pre-set questions but they can be removed, and edits or new ones can be added. If the user wants players to win rewards from winning a quiz, this can also be setup in the config. It is available for free to the public.

This was the first project I worked on, and I created this whilst learning how to code with Spigot API (Minecraft). Since then, I have refactored the code and a handful of times, to try to improve readability, performance and to better abide by coding standards.

It is a multi-modular project, that uses reflection to load the correct module based on the Minecraft version and the Minecraft server platform the server is running. Different versions of java are also used depending on which module gets loaded. It is important for me that my plugins are compatible with as many versions of Minecraft as possible.
